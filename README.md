# QuotaPin · Codex 余量

一个 0.7 MB 的单文件 Windows 小工具：常驻托盘，随时看清 Codex 的 **5 小时额度**、**7 天额度**、**两者重置时间**，以及**储备重置机会**的剩余次数与最近到期时间。

只在需要时出现——Codex 在前台，桌面右下角浮出两根细进度条；点一下托盘图标，弹出完整数据。

## 数据从哪来

读取 Codex 桌面端已经登录的凭证，直接访问 Codex 客户端自己用的两个内部接口：

| 来源 | 取用字段 | 界面呈现 |
| --- | --- | --- |
| `%USERPROFILE%\.codex\auth.json`（若设了 `CODEX_HOME` 则取该目录） | `tokens.access_token`、`tokens.account_id` | 请求头 `Authorization` / `ChatGPT-Account-Id` |
| `GET /backend-api/wham/usage` | `rate_limit.primary_window`（18000s） | 「5 小时」剩余百分比、进度条、重置时间 |
| 同上 | `rate_limit.secondary_window`（604800s） | 「7 天」剩余百分比、进度条、重置时间 |
| 同上 | `additional_rate_limits[]` | 若存在，追加为额外行（不额外造数据） |
| 同上 | `rate_limit_reset_credits.available_count` | 底部「重置机会 N 次」 |
| `GET /backend-api/wham/rate-limit-reset-credits` | `credits[].{id,title,status,expires_at}` | 「最近到期」时间 + 到期提醒 |

不写文件、不改凭证、不上报任何数据；只有两个 GET 请求，请求头与官方 Codex 客户端一致。

如果不想用别人的脚本取数，这里也是同样一份数据：`auth.json` 的 token 直连这两个接口即可。

## 安装

**绿色版**：把 `QuotaPin.exe` 放到任意位置双击即可。单文件，无运行时依赖（不需要 .NET / WebView2 / VC 运行时）。

**安装版（推荐）**：解压后运行 `install.cmd`，它等价于

```bat
QuotaPin.exe --install
```

逐用户安装，不弹 UAC：

1. 复制自身到 `%LOCALAPPDATA%\QuotaPin\QuotaPin.exe`
2. 写入 `HKCU\...\CurrentVersion\Run`，开机自启
3. 启动

取消开机自启：右键托盘图标 → 「开机自启」取消勾选。完全卸载：先 `--uninstall` 去掉自启项，再删除 `%LOCALAPPDATA%\QuotaPin` 与 `%APPDATA%\QuotaPin`。

## 用法

### 托盘

| 操作 | 结果 |
| --- | --- |
| 左键单击 | 弹出 / 收起额度面板 |
| 右键单击 | 菜单：立即刷新 / 小窗常驻 / 开机自启 / 退出 |
| 悬停 | 提示条：`5h 80% · 7d 92% · 重置机会 3 次` |

托盘图标的**两根柱子就是两根额度条**：左柱 = 5 小时，右柱 = 7 天，颜色随余量变化。数据取不到时两柱转灰。

### 小窗

Codex / ChatGPT 窗口在前台时（约 1 秒内响应），桌面右下角出现一张小卡片：

```
┌──────────────────────┐
│ 5h  ▓▓▓▓▓▓▓░░   80%  │
│ 7d  ▓▓▓▓▓▓▓▓▓░  92%  │
└──────────────────────┘
```

- **拖动**：按住左键拖到任意位置，松手即记住（重开程序仍在原处，多屏按所在显示器夹取）
- **单击**：在卡片旁弹出完整面板
- **悬停**：边框与底色轻微提亮
- **右键**：同一个菜单
- 不想让它跟着 Codex 出现/消失，就右键勾「小窗常驻」

### 面板

- **悬停某一行**：该行高亮，表示可点击
- **点击任意行**：在「剩余 / 已用」之间切换（数字与进度条同步切换，标签会显示「· 已用」），选择会被记住
- **底部**：重置机会次数 + 最近一次到期时间；请求失败时这里直接显示失败原因
- 点面板外部自动收起

### 颜色含义

| 余量 | 颜色 | 含义 |
| --- | --- | --- |
| ≥ 40% | 绿 `#2FA85B` | 宽裕 |
| 20% – 40% | 琥珀 `#C08A0E` | 注意 |
| < 20% | 红 `#E04B4B` | 快用完 |
| 灰 | `#B6BCC6` / `#555C67` | 数据过期或请求失败 |

数字保持中性色，只有进入 20% 以下才染红——颜色用来提示，不用来装饰。

## 通知

全部走 Windows 通知中心（托盘气泡形态，会进「通知中心」历史）。

| 触发 | 时机 | 典型内容 |
| --- | --- | --- |
| 余量跌破整 20% 节点 | 剩余 80 / 60 / 40 / 20 / 0% 各一次，两种额度**各自独立** | 标题「5 小时额度剩余 40%」，正文「已用 60% · 重置 18:20（2 小时 46 分后）」 |
| 额度用尽 | 剩余 0% | 标题「5 小时额度已用尽」，带警告图标 |
| 额度重置 | 已用百分比明显回落（窗口翻篇，或使用了储备重置） | 标题「5 小时额度已重置」 |
| 储备重置机会快到期 | 到期前 3 天内，当天 **10:00** 提醒一次，每个机会只提醒一次 | 标题「2 次重置机会即将到期」，正文「最早 10-23 02:13 到期」 |

要点：

- **首次启动不刷屏**：第一次取到数据只记录当前档位，不补发历史节点通知
- **同档位只响一次**：连续多次轮询落在同一 20% 区间内不会重复提醒；只有跌破新节点才再响
- 档位与已提醒的机会 ID 都写在 `%APPDATA%\QuotaPin\state.json`，重启不会重复提醒
- 系统「专注助手 / 勿扰」会按你的设置压掉通知，程序不绕过

## 轮询节奏

| 场景 | 间隔 |
| --- | --- |
| 本机 `codex.exe` / `chatgpt.exe` 在运行 | **3 分钟** |
| 都没运行（只看网页版 / 没开机） | **30 分钟** |
| 请求失败 | 60 秒后重试，连续失败 3 次后回到常规间隔 |
| 手动「立即刷新」 | 立刻一次 |

前台探测独立于网络轮询，约每秒一次 `GetForegroundWindow` + 进程名比对，几乎不耗电。

## 资源占用

实测（Windows 11，1920×1080，100% 缩放）：

| 指标 | 数值 |
| --- | --- |
| 可执行文件 | **673 KB**（含图标 + 版本信息，无外部 DLL） |
| 空闲工作集 | **1 – 2.5 MB** |
| 面板打开时 | **约 4.5 MB** |
| CPU | **0.08%**（单核占比，含每秒前台探测） |
| 句柄 | 几十个 GDI/USER 对象，无累积增长 |

实现上没有 WebView、没有 .NET、没有 GC；空闲 30 秒后会把工作集主动归还系统，所以任务管理器里看到的是 1 MB 上下。首次 HTTPS 握手后瞬时会有一次约 15 MB 的峰值（TLS 库页面），30 秒内回落。

## 常见问题

**提示「找不到 Codex 凭证」**
需要先用 ChatGPT 账号登录过 Codex 桌面端或 CLI，`%USERPROFILE%\.codex\auth.json` 才会存在。只配置了 API key 的账号拿不到这套额度数据。

**提示「HTTP 401：登录已失效」**
打开 Codex 客户端重新登录一次即可，QuotaPin 不需要重启（下次轮询自动恢复）。

**托盘里找不到图标**
Windows 11 默认把新图标收进「^」溢出区。拖到任务栏常驻即可；此时点击仍然正常，面板会贴着溢出按钮弹出。

**小窗不出现**
小窗只在 `codex.exe` / `chatgpt.exe` 处于前台时出现。如果你用的是别的进程名（自编译、改名版），在 `%APPDATA%\QuotaPin\state.json` 的 `extra_procs` 里加一行小写 exe 名即可，例如：

```json
"extra_procs": ["my-codex.exe"]
```

**数据一直是灰的**
说明最近一次请求失败。面板底部会显示原因；托盘提示条也会标「更新失败」。

**会不会被判定为异常访问？**
只用你自己机器上的登录凭证，走官方客户端同样的接口、同样的 Header，频率比客户端本身低得多（3 分钟 / 30 分钟一次）。

## 从源码构建

需要 Rust（MSVC toolchain）与 Windows SDK 的 `rc.exe`（没有也能编，只是 exe 少了图标）。

```powershell
cargo build --release         # target/release/QuotaPin.exe
cargo test --release          # 12 项逻辑测试
pwsh -NoProfile -File scripts/build.ps1   # 构建 + 测试 + 打包 dist/QuotaPin-0.1.0-win64.zip
```

设计取舍、数据流、状态机、UI 度量与渲染管线见 **[DEVDOC.md](DEVDOC.md)**。
