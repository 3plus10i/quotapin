# QuotaPin

看 Codex 还剩多少额度的小工具：常驻托盘，一个图标 + 一个面板，显示 **5 小时额度**、**7 天额度**、**两者的重置时间**和**重置机会**。

单文件 419 KB，双击即用，不需要安装，也不需要 .NET / WebView2。

## 怎么用

1. **双击 `QuotaPin.exe`** —— 托盘出现沙漏图标，从此常驻后台。图标里的沙子跟着 **5 小时余量**往下漏：八成以上是满的，两成到八成空掉一半，跌破两成就快见底了。
2. **左键单击图标** —— 弹出上面的面板；点面板外任意位置收起。
3. **右键单击图标** —— 立即刷新 / 小窗常驻 / 开机自启 / 退出。

想把程序换个位置？随便移，`QuotaPin.exe` 不写注册表也不落地安装，只有一份状态文件在 `%APPDATA%\QuotaPin\`。

## 面板里看什么

| 位置 | 含义 |
| --- | --- |
| 最上面一行 | 整体状态 + 「更新 刚刚」（多久之前取的数据） |
| `5 小时` 行 | 5 小时窗口的余量百分比、进度条、重置时间与倒计时 |
| `7 天` 行 | 7 天窗口，同样的四项；**它的进度条比上面那条粗一倍**，一眼分清是哪一个 |
| 底部 | 「重置机会 N 次」+ 最近一次的到期时间 |

颜色就是全部结论：**绿**宽松、**琥珀**该留意了、**红**快用了、**灰**数据没取到。点任意一行可以在「剩余 / 已用」之间切换，方便对照别处的用量数字。

## 小窗

Codex 或 ChatGPT 窗口在前台时，桌面右下角会浮出一张两行的小卡片（`5h` / `7d` 两条进度条），切走就消失：

<p align="center"><img src="docs/images/mini-light.png" width="180" alt="小窗"></p>

按住左键可拖动，位置会记住；单击它弹出完整面板。不想让它自动隐藏，右键菜单里勾「小窗常驻」。

## 通知

到点会主动提醒，只用 Windows 通知中心，别的时间一概安静：

| 什么时候 | 提醒什么 |
| --- | --- |
| 余量跌破 80 / 60 / 40 / 20 / 0% | 每个节点各一次，5 小时与 7 天各自计算 |
| 额度重置（窗口翻篇或用掉重置机会） | 「额度已重置」，附新周期信息 |
| 重置机会到期前 3 天内 | 当天 10:00 提醒一次，每个机会只提醒一次 |

首次启动只记录当前状态、不补发历史通知；同一个节点不会重复提醒，重启也一样。

## 数据从哪来

读取本机 Codex 已经登录的凭证（`%USERPROFILE%\.codex\auth.json`），直接请求 Codex 客户端自己用的两个接口，只取余量、重置时间、重置机会这三类字段。

**不上报任何数据，不修改凭证，不落任何缓存**。取数频率：Codex 在运行时 3 分钟一次，没运行时 30 分钟一次。

## 常见问题

**托盘里没有图标？** Windows 11 默认把新图标收进「^」溢出区，拖到任务栏上即可（此时点击也正常）。

**提示「找不到 Codex 凭证」？** 需要先用 ChatGPT 账号登录过 Codex 桌面端或 CLI。只配了 API key 的账号拿不到这套额度数据。

**提示「HTTP 401」？** 登录过期了，打开 Codex 重新登录一次，QuotaPin 下次取数会自动恢复，不用重启。

**数字变灰了？** 最近一次请求失败，面板底部会写出原因。
